# 🎬 NOVAPLAYER

### 🚀 Modern Local Image & Video Player

**NOVAPLAYER** is a modern, futuristic, browser-based **Image & Video Player** built using **HTML5, CSS3, and Vanilla JavaScript**.

It allows users to open **multiple images, multiple videos, or entire folders** and browse, view, and play their media through a beautiful desktop-style interface — directly inside the browser.

> 🌌 **NOVAPLAYER — Your Media. Your Device. Your Universe.**

Your media files are **not uploaded to a server**.

```text

      ↓

      │
      ↓

      │
      ↓

      ✕
      │

```

Your photos and videos remain on your device.

# ⚡ Performance

NOVAPLAYER uses:

```javascript
URL.createObjectURL(file)
```

for local media previews and playback.

This avoids unnecessarily converting large media files into Base64 strings and helps reduce memory overhead.

The application is designed to work with **large media collections containing hundreds of files**.

# 💾 Local Preferences

NOVAPLAYER can use browser `localStorage` to remember interface preferences.

Possible preferences include:

* 🎨 Theme settings
* ↕️ Sort order
* 🔎 Selected filter
* 🎞️ Slideshow interval
* ⚙️ Player preferences

> Media files themselves are not stored in LocalStorage.
